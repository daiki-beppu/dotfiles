# Double-blind test

対象に合うシナリオ・ルーブリック・実行者と評価者を設計する。反復改善の依頼は `empirical-prompt-tuning`、改善前後の盲検比較はこちらで扱う。

- 実行前にシナリオ、pass/fail 基準、試行数と終了条件を固定する。
- 条件を中立名で無作為に割り当て、対応をファイルに封印し、採点回収後に開く。条件を推測できる名前・サイズなどを評価材料に含めない。
- 実行者と評価者には比較実験であることや意図した結論を渡さない。回答はファイル経由で回収し、実験者も採点終了まで読まない。

条件漏洩があれば該当試行を無効にし、評価に混ぜない。再試行は事前の上限内で行い、漏洩や利用できない独立評価手段で盲検が成立しなければ、その限界を報告する。結果は採点根拠・試行数・ばらつきとともに示し、少数試行を一般的な優位性と断定しない。
