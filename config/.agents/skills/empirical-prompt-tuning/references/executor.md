# 実行者への依頼

独立した実行評価を開始するとき、必要な部分だけ使う。実行者に比較条件・期待する結論・過去の修正履歴を伝えない。

```text
<対象 SKILL.md の絶対パス、または対象指示>

依頼: <実際のユーザー依頼に相当するタスク>
入力資料: <実行に必要なファイル>
環境と範囲: <隔離作業先、許可されたツールと副作用>

この依頼を実行し、成果物のパスと確認結果を返す。
解釈に迷った箇所、裁量で補った判断、再試行した理由があれば併記する。
```

採点者は実行前に固定した要件と成果物を照合する。要件達成は達成／部分的／未達で記録し、critical は完全達成のみ合格とする。数値化するなら採点尺度も実行前に固定する。時間・tool 数など異なる環境で比較できない値は、その制約を添える。
