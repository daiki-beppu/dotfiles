# メディア退避

退避依頼があるときだけ使う。外部ドライブを確認し、退避元・退避先・checksum 検証・元データの Trash 移動・symlink 作成を具体化する。ドライブを外すとアプリからアクセスできなくなることも伝える。これらが承認済みなら再確認せず進む。

```bash
rsync -a "<src>/" "/Volumes/<drive>/<dst>/"
rsync -anci "<src>/" "/Volumes/<drive>/<dst>/"
```

コピーと checksum 検証の終了コードが成功し、差分がないことを確認してから `trash "<src>"` と `ln -s "/Volumes/<drive>/<dst>" "<src>"` を行う。失敗や差分があれば元データを保持する。`~/Movies` など特殊ディレクトリ全体を置換せず、中の個別フォルダ単位で扱う。

リンク先とアクセス、Data ボリュームの前後差を確認する。ドライブ不在や失敗は未実行と報告する。`--dry-run` ではコピーも行わない。
