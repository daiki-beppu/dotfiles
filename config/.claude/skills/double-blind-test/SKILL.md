# double-blind-test

手法(シナリオ・ルーブリック・被験者/評価者の立て方)は毎回タスクに合わせて設計する。守るのは盲検の 3 点だけ:

1. シナリオと pass/fail ルーブリックは被験者を起動する前に確定し、以後動かさない
2. 条件は中立名で乱数割当し、対応をファイルに封印して全採点の回収後に開く。割当を推測できる手がかり(スキル名、`wc` 等のサイズ)を自分のコンテキストにも評価者に渡る材料にも出さない — 漏れたら無出力で再抽選
3. 被験者・評価者には比較実験であることを知らせず、回答はファイル経由で受け取り、採点が終わるまで読まない
