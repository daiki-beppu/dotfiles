## 「Opus は遅い」と判断して戻した設定を、測り直して元に戻した話

takt（issue を渡すと、実装・レビュー・修正を複数の AI エージェントで回すツール）の設定で、裁定役のモデルを Opus → Sonnet → Opus と 2 往復させた。裁定役（review-adjudicator）は、レビュー役の指摘を採るか退けるかを裁くエージェントで、1 タスクにつき 1〜3 回走る。遅いと判断して Sonnet に戻した根拠の計測が、実は別のモデルを測っていたと分かり、測り直して Opus に戻した。決定の記録は [#242](https://github.com/daiki-beppu/dotfiles/pull/242)（Opus にした）、[#253](https://github.com/daiki-beppu/dotfiles/pull/253)（Sonnet に戻した）、[#254](https://github.com/daiki-beppu/dotfiles/pull/254)（別モデルで動いていた原因の修正）、[#258](https://github.com/daiki-beppu/dotfiles/pull/258)（Opus に戻した）。

### 1. 「モデル X は遅い」と結論する前に、実際に応答したモデルの ID をログで確かめる

10/5 に裁定役を Opus にしたあと、takt の run 1 本の所要時間が平均 19 分から 86 分に伸びた。セッションログ 107 本を集計すると、裁定の 1 回が 1.1 分から 9.0 分になっていて、30 回で合計 6.2 時間を使っていた。これを根拠に、10/7 に裁定役を Sonnet に戻した（#253）。

ところが同じ日に、takt の Claude の工程が**一世代前の Sonnet 5 / Opus 5** で動いていたと分かった（#254）。takt 0.68 から、Claude は PATH の `claude` CLI ではなく SDK に同梱された Claude Code で動くようになった。その同梱版が Nix のビルドで古い版に固定されていて、`opus` という別名が Opus 5.5 ではなく Opus 5 に解決されていた。つまり「Opus は 9 分かかる」は、Opus 5 の計測だった。

設定ファイルに `opus` と書いてあることと、実際に Opus 5.5 が応答したことは別物だった。確かめるには、セッションログの応答に残るモデル ID と Claude Code の版を数える。

```sh
jq -r 'select(.type=="assistant") | "\(.message.model) \(.version)"' <session>.jsonl | sort | uniq -c
```

#253 を出す前にこれを数えていれば、「Opus 5.5 が遅い」ではなく「古いモデルで動いている」という別の問題として扱えた。

### 2. 戻すときは「何を測って戻したか」と「いつ測り直すか」を書いておく

#253 の PR 本文には、根拠の数字（1 回 1.1 分 → 9.0 分）と、その計測期間（10/6〜7）が書いてあった。そのおかげで、#254 で原因が分かったとき「この期間の数字は Opus 5 のものだ」とすぐ突き合わせられ、#258 で Opus に戻す判断ができた。

#258 では逆向きにも同じことをした。PR 本文に「マージ後に数 run の裁定時間を見て、許容できなければ Sonnet に戻す」と書き、測り直す条件を先に決めておいた。

### 3. 少ない回数でも、比べる相手との差が大きければ判断できる

Opus 5.5 に戻してから、裁定は 3 回走った。

| 時期 | モデル | 裁定 1 回の所要時間 |
|---|---|---|
| 10/1〜10/3 | Sonnet | 20〜110 秒 |
| 10/6〜10/7 昼 | Opus 5 | 250〜840 秒（長い回は 29 分） |
| 10/7 夜〜10/8 朝 | Sonnet 5.5 | 20〜170 秒 |
| 10/8（#258 の後） | Opus 5.5 | 86 秒・203 秒・87 秒 |

3 回では「Sonnet と同じ速さ」とは言えない。203 秒の回は、Sonnet の上限の 170 秒を超えている（この回の対象は、ファイル書き出しの作りを丸ごと移す大きめの変更で、レビューの指摘も多かった）。ただ、確かめたかったのは「Opus にすると 1 回 6〜13 分に延びるか」で、3 回とも 4 分に届いていない。差がこれだけ大きければ、3 回でも十分に否定できる。

何回測れば足りるかは、見分けたい差の大きさで決まる。「5 倍遅いか」を確かめるなら数回で足り、「2 割遅いか」を確かめるなら、ばらつき（Sonnet でも 20〜170 秒）に埋もれるので、もっと回数が要る。今回は前者だったので、3 回で見張りを止めた。
